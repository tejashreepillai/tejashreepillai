## Selected Projects

### [Student Retention & Progression Analytics](https://github.com/tejashreepillai/student-retention-analytics)

A Power BI case study exploring where students stay, withdraw or progress. My work included cleaning enrolment data, connecting enrolment and retention records, developing DAX measures, and designing views for university decision-makers. The repository uses synthetic data to demonstrate the workflow without sharing private student records.

### [Service Marketplace SQL Analytics](https://github.com/tejashreepillai/service-marketplace-sql-analytics)

An Oracle SQL project built around a fictional service marketplace. I designed the relational schema and wrote queries to examine task activity, provider engagement and payment patterns. The sample records are synthetic, and the queries can be run independently.

### [Melbourne Airbnb Price Prediction](https://github.com/tejashreepillai/airbnb-price-prediction)

An independent rebuild of a university group project. I compared a median baseline, Ridge Regression, Random Forest and Gradient Boosting, with preprocessing inside the modelling pipeline to prevent validation leakage. The selected model reduced validation MAE by 27.5% against the baseline. The analysis also examines why predictions are much less reliable for exceptionally expensive listings.
